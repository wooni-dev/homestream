# 📺 homestream

같은 Wi-Fi에 연결된 **휴대폰에서 PC/USB 안의 영상을 브라우저로 재생**하는 로컬 스트리밍 서버입니다.
파이썬 **표준 라이브러리만** 사용하며, 영상을 외부로 업로드하지 않고 내 네트워크 안에서만 전송합니다.

---

## ✨ 특징

- **모바일 전용 UI** — 폴더 탐색 + 다크 테마 영상 플레이어
- **탐색(seek)·일시정지 지원** — HTTP Range 요청 처리로 모바일에서 정상 동작
- **비밀번호 보호** — 선택적 Basic 인증 (`.env`로 설정)
- **간단한 실행 창** — 접속 주소를 보여주는 작은 GUI, 창을 닫으면 서버 종료
- **단일 실행파일(.exe)** — Python 없이 더블클릭 실행 (PyInstaller)
- **읽기 전용** — 파일을 수정·삭제·이동하지 않음
- **의존성 0** — 런타임은 파이썬 표준 라이브러리만 사용

---

## 🧩 요구사항

- **Python 3.13** (검증 버전 3.13.12, [`.python-version`](.python-version)에 고정)
- Windows (드라이브·USB 처리는 Windows 기준)
- PC와 휴대폰이 **같은 Wi-Fi**에 연결

> 표준 라이브러리만 쓰므로 3.9 이상이면 대체로 동작하지만, 권장 버전은 3.13입니다.

---

## 🚀 빠른 시작

```powershell
# 1) 가상환경 생성 (최초 1회)
python -m venv .venv

# 2) 설정 파일 준비 — 예시를 복사 후 내 환경에 맞게 수정
copy .env.example .env

# 3) 실행
.venv\Scripts\python.exe stream_server.py
```

실행하면 접속 주소가 적힌 **작은 창**이 뜹니다:

```
┌─────────────────────────────┐
│  폰에서 아래 주소로 접속하세요   │
│    http://192.168.x.x:8000/ │
│  이 창을 X(닫기)로 닫으면…      │
└─────────────────────────────┘
```

휴대폰 브라우저에 그 주소를 입력하면 폴더·영상 목록이 보이고, 영상을 누르면 재생됩니다.
(비밀번호를 설정했다면 접속 시 아이디/비번을 묻습니다.)

> 창을 닫으면 서버가 꺼집니다. 켜둔 동안만 접속됩니다(최소화는 OK).

## ⚙️ 설정 (`.env`)

코드를 고치지 않고 [`.env`](.env) 파일만 수정합니다.

```ini
# 스트리밍할 영상 폴더 (따옴표 없이 경로만)
SERVE_DIR=D:\Videos

# 접속 비밀번호. AUTH_PASS 를 채우면 인증 ON, 비우면 인증 없음(같은 Wi-Fi 전용)
AUTH_USER=admin
AUTH_PASS=
```

| 키 | 설명 |
|------|------|
| `SERVE_DIR` | 내보낼 영상 폴더 경로 |
| `AUTH_USER` | 접속 아이디 (기본 `admin`) |
| `AUTH_PASS` | 접속 비밀번호. 비우면 인증 비활성화 |

> 우선순위: **실제 환경변수 > `.env` > 코드 기본값**

## 📦 실행파일(.exe)로 만들기

Python 없이 더블클릭으로 실행하고 싶을 때. `.env` 내용이 **exe 안에 포함**됩니다.

```powershell
# PyInstaller 설치 (빌드용, 최초 1회)
.venv\Scripts\python.exe -m pip install pyinstaller

# 빌드 (.env 를 함께 번들, 콘솔 없는 GUI 앱으로)
.venv\Scripts\python.exe -m PyInstaller --onefile --windowed --add-data ".env;." --name stream_server stream_server.py
```

→ `dist\stream_server.exe` 생성. 설정을 바꾸려면 `.env` 수정 후 **재빌드**해야 합니다.

> ⚠️ 비밀번호가 exe 안에 박히므로, 빌드한 exe를 **남에게 공유하지 마세요.**

## 🔒 보안 / 네트워크 범위

- 기본은 **같은 Wi-Fi 안에서만** 접속 가능하며, 인터넷 외부에는 노출되지 않습니다(공유기 NAT + 방화벽).
- 비밀번호(Basic 인증)는 **접근 제한**용이며, **HTTPS가 아니라** 평문(base64)으로 전송됩니다.
  → 외부에서 쓰려면 **Tailscale / WireGuard / SSH 터널** 같은 암호화 통로 안에서 사용하세요. 생 인터넷에 포트 포워딩으로 바로 여는 것은 권장하지 않습니다.
- 카페·회사 등 **모르는 사람과 같은 공용 Wi-Fi**에서는 비밀번호를 꼭 설정하세요.

> ⚠️ **저장소에 올리지 말 것:** 실제 비밀번호가 든 `.env`, 비번이 박힌 `dist\`, 용량 큰 `.venv\`·`build\`. → `.gitignore`로 제외하고 `.env.example`만 공유하세요.

## 🛠 문제 해결

| 증상 | 원인 / 해결 |
|------|------------|
| 폰에서 페이지가 안 열림 | 같은 Wi-Fi인지 확인. 게스트 와이파이는 기기 간 차단될 수 있음 |
| 실행 시 "폴더 없음" 팝업 | USB가 빠졌거나 경로가 바뀜 → `.env`의 `SERVE_DIR` 확인 |
| 영상만 재생 안 됨 | 코덱 문제일 수 있음 (대부분 mp4는 정상) |
| 처음 실행 시 접속 불가 | Windows 방화벽 팝업에서 "개인 네트워크 허용" 클릭 |
| 재빌드 시 `PermissionError` | 이전 exe가 실행 중 → 창을 닫고 다시 빌드 |
